# LLMs como avaliadores de artefatos

Site do projeto da disciplina LEAS 2026/2 (UNIPAMPA): Claude, GPT e Gemini avaliam artefatos do SBSeg e do SBRC como um comitê faria, executando o código num contêiner limpo, e comparamos os selos com os oficiais e com o custo em tokens.

Publicado em https://eduardo-prates.github.io/leas-avaliacao-llm/

Página estática (HTML, CSS e JS, sem build). Os dados vêm de:

- [R-ZW/t9-leas](https://github.com/R-ZW/t9-leas): protocolo, transcrições, registros de execução, tokens e a comparação das três LLMs (T9)
- [R-ZW/t8-leas](https://github.com/R-ZW/t8-leas): protocolo e relatório da T8

Autores: Eduardo Prates Tiadoro, Reinaldo Zimmer Wendt e Miguel Ângelo Bastos Muniz.
